# AltStore Suite 用户使用手册

> 版本：v1.0.0　适用平台：macOS / Windows / iOS

本手册介绍一套类 [AltStore](https://altstore.io) 的 iOS 应用侧载系统 —— **AltStore Suite**。它由主机端服务（AltServer）和 iOS 客户端（AltStore）组成，帮助你在不受 App Store 应用商店限制的情况下，使用自己的 Apple 开发者证书或个人 Apple ID 签名并安装 IPA 应用到 iPhone / iPad。

## 1. 产品简介

AltStore Suite 通过"电脑（AltServer）+ 手机（AltStore）"的方式实现应用侧载：

- **AltServer**（电脑端）负责：
  - 发现与配对连接的 iOS 设备；
  - 下载、管理开发者证书；
  - 对 IPA 进行代码签名；
  - 向设备安装 / 刷新应用；
  - 通过本地 HTTP 服务（端口 `27000`）与 iOS 客户端通信。
- **AltStore**（手机端）负责：
  - 浏览已安装应用与可用应用源；
  - 发起安装、刷新签名请求；
  - 展示连接状态与证书状态。

典型工作流程：

```
[第1步] 电脑上运行 AltServer
[第2步] 用数据线连接 iPhone/iPad，完成信任与配对
[第3步] 通过 AltServer 把 AltStore.ipa 安装到设备
[第4步] 在手机上用 AltStore 浏览应用源、一键安装并定期刷新签名
```

## 2. 组件组成

| 组件 | 形式 | 作用 |
|------|------|------|
| **AltSign** | Swift Package（核心库） | IPA 解析、签名引擎、Apple 开发者门户 API、证书管理、设备通信 |
| **AltServer (macOS)** | 命令行工具（`AltServer.dmg`） | macOS 主机端服务 |
| **AltServer (Windows)** | WPF 桌面程序（`AltServer-Windows.zip`） | Windows 主机端服务，带图形界面与系统托盘 |
| **AltStore** | iOS App（`AltStore.ipa`） | 手机端客户端 |
| **AltStore PAL** | iOS App（`AltStore-PAL.ipa`） | 面向欧盟"替代应用市场"（EU Alternative Marketplace）的版本 |

## 3. 系统要求

### AltServer（电脑端）

| 平台 | 版本要求 | 备注 |
|------|----------|------|
| macOS | **13.0 及以上** | Apple Silicon（如 M1/M2/M3）或 Intel Mac |
| Windows | **10 / 11（64 位 x64）** | 需要安装 [iTunes 或 Apple Devices](https://support.apple.com/zh-cn/HT210384) 以获得设备驱动 |

| 项目 | 要求 |
|------|------|
| iOS 设备 | iPhone / iPad，系统 **iOS 16.0 及以上** |
| Apple ID | 用于签名；免费 Apple ID 即可（应用签名 7 天有效） |
| 数据线 | 首次安装建议使用支持数据传输的原装 / MFi 数据线 |
| 网络 | 电脑与手机处于同一局域网（Wi-Fi 刷新时） |

> **注意**：免费 Apple ID 签名的应用 **7 天** 过期，过期后需要重新安装或刷新；付费开发者账号（Apple Developer Program）签名的应用可保持 **1 年**。

## 6. macOS 版 AltServer

### 6.1 安装

1. 双击挂载 `AltServer.dmg`；
2. 将 `AltServer` 拖入「应用程序」文件夹；
3. 打开「应用程序」中的 `AltServer`，或在终端中执行：

```bash
# 查看版本
/Applications/AltServer/AltServer version
```

> 首次运行若提示无法打开，请在「系统设置 → 隐私与安全性」中点击「仍要打开」。

### 6.2 命令行参考

AltServer 是命令行工具，常用命令如下：

```bash
# 列出已连接的 iOS 设备
AltServer devices

# 安装 IPA 到设备（不指定设备时自动选择第一台已连接设备）
AltServer install /path/to/app.ipa
AltServer install /path/to/app.ipa --device <UDID>

# 刷新签名（重新签名并重装已过期的应用）
AltServer refresh
AltServer refresh --device <UDID>

# 管理开发者证书
AltServer certs --apple-id <你的AppleID邮箱> --team-id <团队ID>

# 启动守护进程（后台服务，iOS 客户端通过端口 27000 连接）
AltServer server

# 查看版本
AltServer version
```

### 6.3 守护进程

```bash
AltServer server
```

- 启动后在本机 `27000` 端口监听来自 iOS 客户端的请求；
- 内置 **每 6 小时自动刷新** 计时器，自动为连接的设备签到期的应用；
- 需要保持运行状态；关闭终端或按 `Ctrl+C` 即可停止。

## 7. Windows 版 AltServer

### 7.1 安装

1. 用资源管理器打开 `AltServer-Windows.zip`，右键选择「全部提取」，解压到一个文件夹（例如 `C:\AltServer`）；
2. 进入解压目录，双击 **`AltServer.exe`** 启动；
3. 程序会出现在右下角系统托盘，主窗口将自动打开并扫描设备。

> 发布包为**自包含单文件**，目标电脑无需单独安装 .NET 8。

### 7.2 Windows 工具依赖配置

Windows 版依赖两个外部工具，放在 AltServer 的 `tools\` 子目录下：

| 工具文件 | 用途 | 来源 |
|----------|------|------|
| `idevice_id.exe` | 设备发现 | [libimobiledevice-win32](https://github.com/libimobiledevice-win32/imobiledevice-net/releases) |
| `ideviceinfo.exe` | 读取设备信息 | 同上 |
| `ideviceinstaller.exe` | 安装 / 卸载应用 | 同上 |
| `idevicepair.exe` | 设备配对 | 同上 |
| `zsign.exe` | IPA 代码签名 | [zsign](https://github.com/zhlynn/zsign/releases) |

#### 方式一：自动下载（推荐）

在 `AltServer.exe` 所在目录打开 PowerShell，执行：

```powershell
.\scripts\download-windows-tools.ps1 -OutputDir tools
```

完成后会在当前目录生成 `tools\` 文件夹（你可能需要把脚本放到 AltServer 同级，或按实际路径调整）。

#### 方式二：手动下载

1. 从上面两个 Releases 页面分别下载对应版本；
2. 解压得到上述 5 个 `.exe`；
3. 全部放入 `AltServer.exe` 同级的 `tools\` 文件夹；
4. 重新启动 AltServer，主界面「工具状态」应显示全部就绪。

> 若 `tools\` 缺失，程序启动时会提示"工具未找到"并禁用安装/签名功能。

### 7.3 图形界面使用

主窗口主要区域：

| 区域 | 说明 |
|------|------|
| 设备列表 | 显示已连接设备（名称 / UDID / 型号 / iOS 版本） |
| 刷新按钮 | 手动触发签名刷新 |
| 日志区 / 日志文件 | 查看安装与错误日志，便于排障 |
| 工具状态 | 显示 libimobiledevice 与 zsign 是否可用 |
| 系统托盘菜单 | 显示 / 隐藏主窗口、暂停服务、退出 |

> 端口 `27000` 的本地 HTTP 服务会在启动时自动开启，供 iOS 客户端连接。

## 8. 安装 AltStore 到 iOS 设备

第一次安装必须使用数据线连接，后续刷新可以通过 Wi-Fi。

### 8.1 事前准备

1. **安装驱动**（Windows）：确认已安装 iTunes 或 Apple Devices，这样电脑才能识别 iPhone / iPad；
2. **连接设备**：用数据线将 iPhone / iPad 连接到电脑；
3. **信任电脑**：在设备上会弹出"信任此电脑？"对话框，点击 **信任** 并输入锁屏密码；
4. **确认设备已配对**：部分情况需要在 iPhone「设置 → 通用 → VPN与设备管理」中找到开发者 App 信任选项，详情见 [8.2]。

### 8.2 安装流程

**macOS：**

```bash
# 1. 确认设备已被识别
AltServer devices

# 2. 安装 AltStore
AltServer install /path/to/AltStore.ipa
```

**Windows：**

1. 打开 AltServer.exe，确认设备出现在设备列表；
2. 点击主界面的「安装 IPA」按钮，选择 `AltStore.ipa`；
3. 等待安装完成（设备上会短暂显示安装进度）。

### 8.3 安装后

1. 在设备上首次打开 **AltStore**，系统会提示"不受信任的开发者"；
2. 前往 **iPhone「设置 → 通用 → VPN与设备管理」**；
3. 找到对应的开发者描述文件，点击 **信任**；
4. 返回桌面即可正常打开 AltStore。

> 以后要安装**其他应用**，直接在电脑上 `AltServer install xxx.ipa`，或由 AltStore 客户端从应用源中一键安装。

## 9. AltStore 客户端使用

### 9.1 连接状态

打开 AltStore 后，顶部会显示与 AltServer 的连接状态：

| 状态 | 含义 |
|------|------|
| 已连接 | 电脑端 AltServer 正常运行（端口 27000），可进行刷新 |
| 连接失败 | AltServer 未运行、防火墙拦截或网络不同，请检查电脑端 |

### 9.2 界面分区

| 标签页 | 功能 |
|--------|------|
| **应用**（Apps） | 已安装应用列表，显示版本、剩余签名有效期，支持一键刷新 |
| **源**（Sources） | 管理第三方应用源，浏览源内应用 |
| **设置**（Settings） | 连接信息、证书状态、基础设置 |

### 9.3 安装应用

- 在「源」中浏览应用 → 点击 **安装**；
- 或由电脑端命令行安装（macOS）：

```bash
AltServer install /path/to/app.ipa
```

安装完成后可在「应用」页看到该应用。

### 9.4 手动刷新

在「应用」页点击「刷新全部」或在电脑端执行：

```bash
AltServer refresh
```

## 10. 应用源（Source）格式

AltStore 通过 **JSON 格式的应用源** 发现应用。源是一个托管在 HTTPS 上的 JSON 文件。

### 10.1 完整字段

```json
{
  "apps": [
    {
      "name": "示例应用",
      "bundleIdentifier": "com.example.app",
      "version": "1.0.0",
      "versionDate": "2026-01-01",
      "downloadURL": "https://example.com/app.ipa",
      "localizedDescription": "应用的详细描述",
      "iconURL": "https://example.com/icon.png",
      "tintColor": "#FF0000",
      "screenshots": [
        { "imageURL": "https://example.com/s1.png", "size": "iphone" }
      ],
      "appPermissions": {
        "entitlements": [],
        "privacy": []
      }
    }
  ],
  "news": [
    {
      "title": "站内公告",
      "imageURL": "https://example.com/news.png",
      "date": "2026-01-01"
    }
  ]
}
```

### 10.2 字段说明

`apps` 数组中的每一项：

| 字段 | 必需 | 类型 | 说明 |
|------|:---:|------|------|
| `name` | 是 | string | 应用名称 |
| `bundleIdentifier` | 是 | string | 应用唯一标识（如 `com.example.app`） |
| `version` | 是 | string | 显示版本号 |
| `versionDate` | 是 | string | 版本发布日期（ISO 8601，如 `2026-01-01`） |
| `downloadURL` | 是 | string | 指向 **.ipa** 文件的 HTTPS 下载地址 |
| `localizedDescription` | 否 | string | 应用描述 |
| `iconURL` | 否 | string | 应用图标（PNG，建议 512x512） |
| `tintColor` | 否 | string | 界面强调色（十六进制，如 `#FF0000`） |
| `screenshots` | 否 | array | 截图列表（`imageURL` + `size`） |
| `appPermissions` | 否 | object | `entitlements`（权限声明）与 `privacy`（隐私信息）数组 |

`news` 数组（可选）用于在 AltStore 首页展示公告。

### 10.3 注意事项

- `downloadURL` 与 `iconURL` 必须为 **HTTPS**，且拥有有效的 SSL 证书；
- 提供源的域名需支持 CORS（`Access-Control-Allow-Origin`），否则 AltStore 可能无法解析；
- 源文件建议命名为 `apps.json` 并托管在静态托管平台（如 GitHub Pages、Cloudflare Pages）。

## 11. 签名刷新机制

设备端运行 **AltServer 守护进程标配每 6 小时自动刷新一次**，为你签名的应用续期：

- 免费 Apple ID：签名 **7 天** 有效，建议每周至少让 AltServer 运行并联网一次；
- 开发者账号：签名 **366 天** 有效；
- 刷新条件：AltServer 正在运行，且设备通过 **USB 或同一 Wi-Fi** 与电脑可达。

> 提示：长期不刷新会导致签名过期，应用将无法打开。设置一个每周提醒最稳妥。

## 12. 网络与端口

| 项 | 值 |
|----|----|
| 通信端口 | **27000**（TCP，本机 HTTP 服务） |
| 通信协议 | 自定义 HTTP/1.1 风格协议（JSON 请求/响应） |
| 端口用途 | iOS 客户端从本机访问 AltServer |
| 默认监听地址 | `127.0.0.1`（仅本机回环） |

**防火墙**：如果在局域网内使用 Wi-Fi 刷新，请确保：

- macOS：在「系统设置 → 网络 → 防火墙」中允许 AltServer 接受传入连接；
- Windows：首次启动时在"Windows 安全中心"弹窗中为 AltServer 勾选「专用网络」并允许。

## 13. 疑难解答（FAQ）

| 现象 | 可能原因 | 解决办法 |
|------|----------|----------|
| `devices` 显示无设备 | 驱动未安装 / 数据线仅充电 | 安装 iTunes 或 Apple Devices；换支持数据的原装线 |
| 提示"设备未配对 / 请信任此电脑" | 未在手机上完成信任 | 手机上弹出信任框时点「信任」；或在「通用 → 关于本机」重置配对后重连 |
| AltStore 打开即崩溃 | 签名过期 | 重新用 AltServer 安装 / 刷新 |
| AltStore 提示"不受信任的开发者" | 未信任开发者描述文件 | 「设置 → 通用 → VPN与设备管理」→ 信任 |
| 客户端显示"连接失败" | AltServer 未运行 / 端口被占 / 防火墙 | 启动 AltServer；确认端口 27000 未被占用；放行防火墙 |
| Windows 提示"工具未找到" | `tools\` 缺失 | 运行 `download-windows-tools.ps1` 或手动放置 5 个 exe |
| 安装进度卡住或失败 | 配对过期 / 网线直连 / 磁盘空间 | 重新配对；改用 USB；清除设备存储空间 |
| 端口 27000 被占用 | 上次进程未退出 | 结束占用进程后重启 AltServer |
| 刷新失败 | Wi-Fi 网络隔离 / 驱动异常 | 改用 USB 重试；检查电脑与手机是否同一网络 |

### 错误码速查

| 错误 | 含义 |
|------|------|
| `No devices found` | 未检测到 iOS 设备，检查连接与驱动 |
| `Device not paired` | 设备未信任该电脑 |
| `IPA path required` | 未提供 IPA 路径 |
| `No certificates found` | 该 Apple ID / 团队下没有可用证书 |
| HTTP 400 | 请求缺少必要参数（如 `ipaPath`） |
| HTTP 404 | AltServer 未找到对应设备或资源 |
| HTTP 500 | AltServer 内部错误，查看日志定位 |

## 14. 从源码构建（开发人员）

> 以下内容面向开发人员，普通用户可跳过。

### 前置依赖

- macOS：Xcode 15.0+、Swift 5.9+
- Windows：.NET 8.0+ SDK

### macOS（AltSign 库 + AltServer）

```bash
# 构建发布版 AltServer（输出 .build/release/AltServerCLI）
swift build -c release --product AltServerCLI

# 运行单元测试
swift test

# 构建 iOS 客户端（需 Xcode）
xcodebuild -project AltStore/AltStore.xcodeproj \
  -scheme AltStore \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  build
```

### Windows（AltServer）

```powershell
# 下载工具依赖
pwsh .\scripts\download-windows-tools.ps1

# 发布自包含单文件
dotnet publish AltServer.Windows/AltServer.Windows.csproj `
  -c Release `
  --self-contained true `
  -r win-x64 `
  -p:PublishSingleFile=true `
  -o build/AltServer-Windows
```

### 一键发布（GitHub Actions）

推送形如 `v*` 的 tag（如 `git tag v1.0.0 && git push origin v1.0.0`）会自动触发 `build-release.yml`，产出 4 个发布物对应的 IPA / DMG / ZIP。

## 15. 卸载

### iOS 端

在 iPhone / iPad 上长按 AltStore 图标 → 删除 App。已安装的其他侧载应用同样可直接删除。

### macOS 端

把「应用程序」中的 AltServer 拖入废纸篓即可（无后台残留）。

### Windows 端

1. 右键系统托盘图标 → 退出；
2. 直接删除 AltServer 文件夹（含 `tools\`）；
3. 如需彻底清理日志与设置：删除 `%APPDATA%\AltServer` 目录。

## 17. 当前版本已知限制

为了让发布物可以无证书地在 CI 上构建，v1.0.0 存在以下已知限制，计划在后续版本完善：

1. iOS 客户端在标准版与 PAL 版中当前共用同一套工程与包标识，PAL 版输出内容与标准版一致；
2. CI 上构建的 IPA 为**未签名**包（`CODE_SIGNING_ALLOWED=NO`），需通过 AltServer 首次安装时完成签名，不能在设备上直接"信任即用"；
3. `cert` 命令当前使用占位密码流程，真实 Apple 门户交互尚未完全接通；
4. `refresh` 命令当前主要为列出/检查已安装应用，完整重签刷新流程待接入；
5. `tools\` 下载脚本需根据网络环境微调镜像地址。
